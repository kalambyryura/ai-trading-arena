# Owner actions

Kept by coord. The numbered queue of everything only the owner can do. The lead passes it to the owner and batches questions.

- Numbers are never reused. Statuses: WAITING · DONE · CANCELLED · LATER.
- Each action names the exact steps, file names and hashes (for example "install kit `<file>` sha256 `<hash>` between runs, after a backup"), so the owner can act without reading anything else.
- When the owner is done, record the outcome and the time from the clock; link the evidence file.
